# Элэг: дотогшоо аялал (demo)

Хүний биеэс митохондри хүртэл scroll хийж дотогшоо ордог 3D сургалтын вэб.

## Ажиллуулах

1. [Node.js](https://nodejs.org) 20 буюу түүнээс шинэ хувилбар суулгасан байх хэрэгтэй.
2. Энэ фолдер дотор терминал (PowerShell) нээгээд:

```
npm install
npm run dev
```

3. Хөтөч дээр http://localhost:3000 хаягийг нээнэ.

## Бүтэц

- `content/levels.ts`: бүх монгол текст (багшаар шалгуулах хэрэгтэй)
- `public/models/`: их бие, эрүүл/өөхжсөн/хатуурсан элэгний .glb модел
- `components/three/levels/`: түвшин бүрийн 3D хэсэг (дэлбэнцэр, эс, митохондрийг кодоор үүсгэсэн)
- `components/Experience.tsx`: scroll, карт, товчлуурууд
- `scripts/`: элэгний өвчтэй хувилбарыг үүсгэсэн скриптүүд
